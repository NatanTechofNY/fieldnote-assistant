# Alexa add-on package

`addon-package/addon.json` is the manifest `alexa-ai deploy` uploads. Every `fieldnote.example.com` in it is a placeholder:
replace it with your `PUBLIC_BASE_URL` host before deploying, and host the icon and carousel images and the privacy and
terms pages there (Amazon requires HTTPS PNG/JPG/WEBP images at the sizes listed and valid policy URLs).

The step-by-step setup, account linking, and what the Echo can reach are in [`docs/ALEXA.md`](../docs/ALEXA.md).
